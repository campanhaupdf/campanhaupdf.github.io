CAMPANHA UP — SITE

Esta versão contém:

- index.html
- style.css organizado e comentado
- app.js organizado e comentado
- config.js para Supabase

O site:
- usa amarelo, preto e branco;
- não possui candidaturas;
- não possui imagens;
- não possui rodapé;
- termina no botão ENVIAR CADASTRO;
- permite disponibilidade diferente em cada dia;
- permite manhã, tarde e noite;
- permite horário específico opcional para cada dia.

Para usar:
1. Substitua os arquivos no repositório campanhaupdf.github.io.
2. Mantenha suas credenciais atuais do Supabase no config.js.
3. Faça commit/push.
